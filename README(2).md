# 班级请假系统（Vercel 版）

云端的班级请假系统：全班共用一个网址，数据实时同步。
后端数据库用 Supabase，网页托管在 Vercel，全程免费。

## 包含文件

| 文件 | 作用 |
|---|---|
| `index.html` | 请假系统网页（同学/班长/导员三端合一） |
| `config.js` | **你需要填这个**——填 Supabase 的 URL 和 anon key |
| `vercel.json` | Vercel 托管配置，不用改 |
| `package.json` | 项目说明，不用改 |
| `.gitignore` | 防止误传密钥，不用改 |
| `部署教程.md` | 图文部署步骤 |

## 怎么部署

1. 打开 `config.js`，填好 Supabase 的两个值
2. 把整个文件夹上传到 GitHub 新建的仓库
3. 打开 vercel.com，用 GitHub 登录，Import 这个仓库
4. 一路默认点 Deploy，等一两分钟
5. 拿到 `xxx.vercel.app` 网址，发给全班

详细步骤见 `部署教程.md`。
